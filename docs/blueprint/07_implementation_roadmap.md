# Implementation Roadmap

## Phase 1: Foundation

- Define mission, ideology, doctrine, and glossary.
- Publish the first blueprint.
- Create a simple public site.
- Build a small advisory circle.
- Identify legal and financial experts.
- Start founder and worker research.

## Phase 2: Research and Tooling

- Build the accountability scorecard.
- Research priority sectors.
- Create founder succession guides.
- Create worker ownership explainers.
- Draft legal and capital structure options.
- Identify pilot businesses.

## Phase 3: Pilot Institution

- Form the initial nonprofit or foundation layer.
- Build a transition advisory programme.
- Design the first democratic capital vehicle.
- Recruit operating partners.
- Secure first supporters and anchor backers.

## Phase 4: First Transactions

- Support the first ownership transitions.
- Publish transparent case studies.
- Validate governance structures.
- Refine the scorecard.
- Build public trust.

## Phase 5: Scale

- Expand across sectors.
- Build regional chapters or partner nodes.
- Develop policy proposals.
- Launch broader public education.
- Move from isolated pilots to a replicable economic model.
