# Ownership Accountability Scorecard

The Civiconomy scorecard is a practical framework for assessing how a business is owned, financed, governed, and operated.

## Purpose

The scorecard helps workers, founders, investors, customers, researchers, and citizens understand whether an enterprise is structured for long-term shared value.

## Version 1 Categories

1. Ownership structure
2. Worker voice
3. Worker reward
4. Debt and capital structure
5. Reinvestment
6. Tax conduct
7. Transparency
8. Community impact

## Scoring Scale

Each category is scored from 0 to 5.

- 0 = No meaningful evidence or serious concern
- 1 = Weak practice
- 2 = Basic practice
- 3 = Credible practice
- 4 = Strong practice
- 5 = Leading practice

## Output

A company profile should include:

- Summary grade
- Category scores
- Evidence notes
- Positive indicators
- Warning signs
- Improvement recommendations
- Confidence level

## Principle

The scorecard should separate evidence from judgement. It should show what is known, what is missing, and why a score has been assigned.
